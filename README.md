# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过俯视图、侧视图、重量/空间指标和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 行李箱长宽高、箱体承重、空箱重量与整箱总重上限配置
- 物品清单、类别、尺寸、重量、优先级和必带标记
- 装箱可用物品重量自动取「箱体承重」与「总重上限扣除空箱」的较小值；物品重量、空箱重量、整箱总重与剩余量在方案卡、风险面板和打印单中分别展示
- 确定性三维长方体装箱、旋转与碰撞检测
- 三套方案对比和双投影视图联动
- 空箱超限、超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- localStorage 本地保存与打印清单

空箱重量填 `0` 表示未称量（兼容旧数据）；整箱总重上限留空（`0`）时只按箱体承重规则。空箱本身已超过总重上限时会优先提示箱体超限，即使移除全部物品也不会显示安全。重量恰好达到上限允许装入。

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案预留体积和重量上限；重量上限为「箱体承重」与「整箱总重上限 − 空箱自重」的较小值（未填写总重上限时只用承重），再叠加各方案的预留系数。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

docker compose up --build
